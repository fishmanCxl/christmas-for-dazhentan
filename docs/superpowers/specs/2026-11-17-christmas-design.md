# 掌心里的圣诞奇境

用户已选择 Three.js 与 HTML/CSS 混合方案。交付手机竖屏优先的完整互动网站。

## 体验

邀请页进入雪夜，长按 1.2 秒点亮树，灯光沿树向上流动，划开或点击礼盒拆礼物，水晶球升起，点击水晶球进入烟花祝福，支持重播。

文字采用圣诞祝福。昵称与照片尚未提供，当前采用通用称呼和水晶球内的迷你圣诞树。这是本次实施选择。

## 视觉

四幕共享午夜青色背景、香槟金灯光、奶油白文字、酒红色礼物。Instrument Serif 英文大标题搭配系统中文字体。生成的四场景概念图作为视觉参考，单独生成的雪夜村庄作为静态背景。3D 树、礼盒、水晶球和粒子可实时交互。

## 方案取舍

纯 Three.js 的玻璃和全场景细节成本较高。Canvas 伪 3D 的空间交互较弱。用户选择混合方案，让 Three.js 处理空间对象，HTML/CSS 处理文字和按钮。

## 性能与兼容

一个 WebGL 画布，一个动画循环，实例化装饰和 Shader 雪花。限制 DPR 并依据帧时降档，后台暂停。窄屏 360px 起，适配安全区域和动态视口。减少动态效果偏好下缩短演出并减少粒子。WebGL 失败时保留可操作的降级流程。

音频由首次用户操作启动，使用 Web Audio 合成圣诞旋律和音效。可静音，后台暂停。

## 验收

完整通关与重播，提前松开长按不点灯，重复操作保持单一状态，静音有实际效果，窗口缩放后画面保持正确比例，移动和桌面截图检查，构建和状态测试通过。桌面模拟结果与实际手机性能分别报告。
